Radio Station Plugin Documentation

Plugin File: radio.py

Keywords / Types: audio, radio

Supported Plugin Version: 0.1 (2026.02.09)

Supported Audio Extensions: mp3, m4a, aac, wav, flac, ogg, wma

Purpose: Implements audio-centric broadcasting pipelines. Supports playing standalone random audio tracks or assembling structured, sequenced radio program blocks with background music beds, rotation rules, weighted path selection, and episode sequencing.

Hardware Playback Architecture
Audio output is driven via OMXPlayer using the globally configured player_settings. When background music beds (bed) are specified, the plugin spawns an asynchronous, non-blocking background OMXPlayer instance synchronized to stop automatically when the main foreground audio track finishes.

1. Keyword Handlers

Keyword Target Scope Description
audio Folder pool Selects a random folder from the rule's directory pool and plays a single random audio file from that folder.
radio Structured format block Executes a multi-element radio program sequence defined by the format array. Evaluates each segment in order with support for weighted rotation, background audio beds, loop counts, and tracking.

2. Top-Level Schedule Block Attributes

Radio entries are defined directly in the times array of settings.json[cite: 4, 5].

Field Type Description
name [<string>] Base directory paths for the block (supports macros like %D[1]%)[cite: 4, 5]. Used as the default root for relative paths in the format definition.
type <string> Must be set to either "audio" or "radio" to trigger this plugin.
format [<element>] | [[<element>]] Required for type: "radio". An array of format steps, or a nested array of format variations (if nested, one variation array is chosen at random upon execution).

3. Format Segment Definition (format Array)

Each entry in a format sequence can be a simple string (interpreted as a relative folder path using random selection) or a configuration object with fine-grained control:

Field Type Default Description
path <string> | [<string>] | [<object>] Required Directory or list of candidate directories containing audio assets.
  • Relative to the block's base folder.
  • Absolute path if prefixed with @ (e.g., "@%D[1]%/audio/bumpers").
  • Supports path objects containing conditional special or chance gates.
type <string> "random" Selection algorithm for this segment:
  • random: Selects a random audio file from the resolved directory.
  • commercial: Random selection, but logs playback type as commercial.
  • balanced: Queries the backend to select the least-played file in the folder.
  • ordered: Selects the next sequential file using backend tracking.
  • ordered-show: Randomly picks an episode folder under grandparent directory, then plays the next sequential track.
bed <string> | [<string>] | [<object>] null Directory containing background audio tracks (music beds). A random bed track is spawned in a non-blocking background player and runs concurrently with the primary track, cutting off automatically when the primary track ends.
loop <integer> 1 Number of consecutive times this format step repeats before advancing to the next segment in the array.
cut <integer> | <float> 3 Seconds before the absolute end of the file at which playback is stopped early to allow smooth transitions.
weight [<number>] null Probability weights matching the path array when multiple paths are provided. Uses weighted random choice to select a directory.

4. Conditional Path Structures

Instead of static folder strings, both path and bed accept an array of condition objects. The plugin evaluates each object in order until one satisfies all criteria:

Field Type Description
name <string> | [<string>] The target path or folder list returned if conditions pass.
special <string> Holiday or calendar condition (e.g., "halloween", "xmas")[cite: 4, 5]. Checked against is_special_time().
chance <string> | <float> Evaluated mathematical equation or probability threshold between 0.0 and 1.0[cite: 4, 5].

5. Configuration Examples

5.1 Simple Random Audio Block (type: "audio")

Picks a random folder from the list and plays a single random track from it:

{
    "name": [
        "%D[1]%/music/rock",
        "%D[1]%/music/pop"
    ],
    "type": "audio"
}

5.2 Standard Radio Show Clock with Music Beds (type: "radio")

Executes an hourly station clock: station ID, news bulletin over a background music bed, sequential story episode, two commercial spots, and a music track:

{
    "name": ["%D[1]%/radio_station"],
    "type": "radio",
    "format": [
        {
            "path": "station_ids",
            "type": "random",
            "cut": 0
        },
        {
            "path": "news_reports",
            "type": "ordered",
            "bed": "music_beds/news_theme",
            "cut": 2
        },
        {
            "path": "dramas",
            "type": "ordered-show",
            "cut": 3
        },
        {
            "path": ["ads/local", "ads/national"],
            "weight": [70, 30],
            "type": "commercial",
            "loop": 2,
            "cut": 1
        },
        {
            "path": "music/classic_hits",
            "type": "balanced",
            "cut": 2
        }
    ]
}

5.3 Conditional Seasonal Paths

Switches station liners and music beds based on holiday flags or evaluated probability gates:

{
    "name": ["%D[1]%/radio_station"],
    "type": "radio",
    "format": [
        {
            "path": [
                { "name": "seasonal/halloween_ids", "special": "halloween" },
                { "name": "seasonal/xmas_ids", "special": "xmas" },
                { "name": "bumpers/rare", "chance": "0.10" },
                { "name": "bumpers/general" }
            ],
            "type": "random"
        },
        {
            "path": "music/rotation",
            "type": "balanced"
        }
    ]
}
