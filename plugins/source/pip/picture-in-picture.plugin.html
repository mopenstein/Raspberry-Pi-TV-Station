Picture-in-Picture Plugin Documentation

Plugin File: picture-in-picture.py

Keyword / Type: pip

Supported Plugin Version: 1.6 (2026.10.04)

Purpose: Spawns a multi-layered video presentation leveraging DispmanX hardware layering in OMXPlayer. Runs a primary background video on Layer 1 alongside a secondary windowed video overlay on Layer 2 with support for positional presets, audio ducking, transparency, loop control, and interval delays.

Hardware Layering Architecture
The primary presentation executes on OMXPlayer --layer 1, while the overlay presentation executes on --layer 2. The master timeline is strictly tied to the primary video stream: when the primary video completes playback or encounters an exit condition, all secondary overlay instances are immediately terminated and cleaned up.

1. Schedule Block Structure

PiP rules are defined directly within the standard times schedule array in settings.json using "type": "pip". Configuration parameters are grouped under the primary and overlay objects.

Field Type Description
name [<string>] Target path or directory reference (supports standard macros such as %D[1]%). Acts as the fallback root for relative media sources.
type <string> Must be set to "pip" to trigger the plugin handler.
primary <object> Configuration object defining the primary base video stream running on Layer 1.
overlay <object> Optional configuration object defining the secondary overlay video stream running on Layer 2.

2. Primary Object Configuration

Defines the main background video stream.

Field Type Default Description
source [<string>] | <string> Required Directory or path containing video files. Supports paths relative to the rule's name directory, or absolute paths prefixed with @ (e.g., "@%D[1]%/movies").
type <string> "random" File selection algorithm: "random" (chooses randomly from matching video formats) or "first" (picks the first file alphabetically).
volume <integer> | <float> 10 Audio loudness scaled from 0 to 10. 0 disables hardware audio entirely (-n -1), while 10 represents standard unity gain (0 mB). Clamped to a maximum value of 10.0.

3. Overlay Object Configuration

Defines the secondary floating window video stream.

Field Type Default Description
source [<string>] | <string> Required Target directory containing video assets for the overlay. Supports relative paths and absolute paths with the @ prefix.
type <string> "random" File selection mode across the target directory ("random" or "first").
position [<int>] | <string> "bottom-right" Bounding box coordinates on the 640×480 canvas. Accepts explicit coordinates or named presets:
  • Array: [x1, y1, x2, y2] (e.g., [160, 120, 500, 360]).
  • Presets: "top-right", "top-left", "bottom-right", "bottom-left", "center". Presets default to a 200×150 window adjusted by margin.
margin <integer> 20 Canvas margin in pixels used when position is configured via preset strings.
volume <integer> | <float> 0 Audio volume scale from 0 (muted) to 10 (maximum/unity).
duck-primary <integer> | <float> null When active, dynamically reduces the primary video's volume to this level while the overlay is actively playing. Automatically restores primary volume when the overlay stops or enters a wait interval.
alpha <integer> 255 Overlay window opacity/transparency from 0 (fully invisible) to 255 (fully opaque).
delay / start-offset <float> | <integer> 0 Seconds to wait after the primary video begins before spawning the overlay window for the first time.
duration <float> | <integer> null Maximum seconds an individual overlay video clip is permitted to play before prematurely ending and cycling to the next loop iteration.
wait / sleep <float> | <integer> 0 Cooldown duration (in seconds) between loop cycles. The overlay window closes during this interval and re-spawns once the timer elapses.
max-duration / max-runtime <float> | <integer> null Hard global ceiling in seconds for the overlay stream across all loops combined. Once reached, the overlay is killed permanently for the remainder of the block.
loop <integer> | <null> -1 Controls overlay playback repetition:
  • -1 or null: Loops indefinitely until the primary video finishes.
  • 0: Disables the overlay entirely (runs primary stream only).
  • 1 or greater: Runs for the specified number of loop cycles.
Audio Ducking Timing
If duck-primary is defined and delay is set to 0, the primary stream initializes in a pre-ducked state. If wait is configured between loops, primary audio volume is restored during each wait window and ducked again when the subsequent overlay clip begins.

4. Configuration Examples

4.1 Feature Showcase (All Settings Combined)

Plays a primary feature with a delayed, repeating promotional overlay positioned in the top-right corner. The primary audio ducks during playback and restores during intermediate delays.

{
    "name": ["%D[1]%/broadcast/features"],
    "type": "pip",
    "primary": {
        "source": ["movies/action"],
        "type": "random",
        "volume": 10
    },
    "overlay": {
        "source": ["commercials/promos"],
        "type": "random",
        "position": "top-right",
        "margin": 25,
        "alpha": 220,
        "volume": 10,
        "duck-primary": 3,
        "delay": 15,
        "duration": 10,
        "wait": 5,
        "max-duration": 60,
        "loop": 3
    }
}

4.2 Transparent Corner Bug / Watermark

Displays an ongoing, silent, semi-transparent watermark logo in the bottom-left corner with no audio alteration.

{
    "name": ["%D[1]%/broadcast/shows"],
    "type": "pip",
    "primary": {
        "source": ["sitcoms"],
        "type": "random",
        "volume": 10
    },
    "overlay": {
        "source": ["graphics/station_bugs"],
        "type": "random",
        "position": "bottom-left",
        "margin": 15,
        "alpha": 160,
        "volume": 0,
        "loop": -1
    }
}

4.3 Precise Coordinate Overlay (Custom Window)

Positions a custom 340×240 overlay window centered on the display using explicit coordinates [x1, y1, x2, y2].

{
    "name": ["%D[1]%/broadcast/special"],
    "type": "pip",
    "primary": {
        "source": ["documentaries"],
        "volume": 8
    },
    "overlay": {
        "source": ["trailers"],
        "position": [150, 120, 490, 360],
        "volume": 10,
        "duck-primary": 2,
        "loop": 1
    }
}
