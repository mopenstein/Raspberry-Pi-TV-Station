Programming Configuration Documentation

File Path: settings.json

Supported Settings Version: 0.996 (Script v102.3)

Purpose: Defines the programming and operational rules for the automated broadcast system, controlling media selection, scheduling windows, commercial breaks, bumpers, and maintenance tasks.

CRITICAL: Schedule Evaluation Order
The script iterates through both times and commercial_times in REVERSED order (bottom to top). Rules placed near the bottom of an array evaluate first and take precedence over rules defined earlier in the list.

3. Programming Rules (times Array)

Evaluated bottom-to-top. The first rule matching all criteria executes.

Field Type Description
name [<string>] Array of target directories or video files. Supports macros like %D[n]%, %day_of_week%, and %month%.
type <string> Playback resolution engine:
  • video: Random file from the targeted directories.
  • video-show: Standard random video file selection.
  • balanced-video: Queries local server database to return least-played file across paths.
  • ordered-show: Randomly picks a show subfolder, then plays sequential episodes via server tracking.
  • ordered-video: Selects the next sequential file from targeted folder via server tracking.
  • commercial: Plays a video flagged as a commercial.
  • Plugin-defined: Handled by external plugin handlers.
channel <string> | <null> Restricts rule execution to a matching active channel (wildcards: "all", "any", "*").
set-tag <string> Sets common tag that can be used as a reference for commercials (e.g., kids and family). Overridden if the filename contains an explicit @tag@.
between <object> Compound conditions. Must satisfy all nested groups:
  • dates: Array of single dates ("Oct 31") or date ranges ([["Jun 10", "Aug 31"]]) (OR logic across entries).
  • times: Array of time windows ([["08:00PM", "10:35PM"]]). Supports nested lists for AND conditions.
  • years: Array of allowed years (e.g., [2026]).
start / end [HH, MM] Alternate 24-hour time range format (e.g., [20, 0] to [22, 30]). Accepts wildcard strings ("*").
dayOfWeek [<string>] Allowed days in lowercase (e.g., ["saturday", "sunday"], or ["*"]).
month [<integer>] Allowed calendar months (1–12, or ["*"]).
date [<integer>] Allowed days of the month (1–31, or ["*"]).
special <string> Matches calendar holidays with optional day offsets (e.g., "thanksgiving", "xmas", "easter-5").
chance <string> | <float> Mathematical probability expression evaluated between 0.0 and 1.0, or percentage (e.g., "25%").
minimum-before-repeat <number> | [<min>, <max>] Enforces a cooldown period (in seconds) before this rule or plugin asset can be selected again.
static [true, <seconds>, <channel_name>] Locks the station to this specific schedule block and channel for the specified duration.
prefer-folder <string> | <boolean> If active, randomly selects a folder before picking a video, rather than pooling all files together.
weighted [<number>] | "auto" Weights folder probability when prefer-folder is active. Set to "auto" to weight by file count.
min-length / max-length <integer> Duration filters in seconds applied against %T(duration)% tags embedded in filenames.
random video on first play <boolean> Overrides global setting for ordered-show rules.
bumpers <object> Bumper configurations:
  • in: Folders containing bumpers played coming out of commercial breaks.
  • out: Folders containing bumpers played heading into commercial breaks.
  • chance: Object with in and out probability expressions (e.g., {"in": "50%", "out": "75%"}).
  • show-override: Object ({"in": bool, "out": bool}) allowing local show bumpers to replace global definitions.

4. Commercial Rules (commercial_times Array)

Evaluated bottom-to-top to select commercial pools when commercial insertion is active.

Field Type Description
name [<string>] Folders containing commercial files.
tag <string> Matches against the program's active tag (set-tag or filename @tag@).
channel <string> Restricts commercial pool to the active broadcast channel.
prefer-folder <string> | <boolean> Picks a folder before selecting an ad.
weighted [<number>] Percentage weights summing to 100 for folder selection.

5. Keywords & Expression Engine

Path Macros

  • %D[n]%: Substituted with entry n from the top-level drive array.
  • %day%: Weekday integer (Monday = 0, Sunday = 6).
  • %day_of_week%: Lowercase weekday name (monday–sunday).
  • %month%: Lowercase month name (january–december).
  • %prev-month% / %next-month%: Preceding or subsequent month names.

Time String Placeholders

  • %HOUR%: 12-hour format hour (01–12).
  • %TENSHOUR% / %UNITSHOUR%: Tens or units digit of the current 12-hour value.
  • %MIN%: Minute of the hour (00–59).
  • %TENSMIN% / %UNITSMIN%: Tens or units digit of the current minute.
  • %TOPTENSMIN%: Evaluates strictly to 0 or 3 (for :00–:05 or :30–:35 half-hour block alignment).
  • %AMPM%: Uppercase AM or PM.
  • %MONTH%: 3-letter month abbreviation (e.g., Oct).
  • %DAY%: Zero-padded day of month (01–31).
  • %YEAR%: 4-digit year.
  • %MAXDAYS%: Dynamic day count of the current month.

Supported Holidays (special)

Accepts optional numeric day offsets (e.g., "easter-5"):

thanksgiving, xmas (period between Thanksgiving and Dec 25), christmas (Dec 25), halloween, mothers day, fathers day, memorial day, easter, new years day, mlk day, valentines day, presidents day, st patricks day, april fools day, independence day (or 4th of july), labor day, columbus day, veterans day, christmaseve, new years eve.

Details on References

Settings can refer to variables defined within the vars object. This aids in creating reusable, configurable values. The format is $ref/var_name/index/or/key. The variable must be defined before it is referenced.

"vars": {
    "cartoons": { "am": { "start": [4, 0], "end": [10, 45] }, "pm": { "start": [15, 0], "end": [16, 45] } }
},

"times": [{
    "name": ["%D[1]%/cartoons/am"],
    "start": "$ref/cartoons/am/start",
    "end": "$ref/cartoons/am/end",
    "type": "video"
},
{
    "name": ["%D[1]%/cartoons/pm"],
    "start": "$ref/cartoons/pm/start",
    "end": "$ref/cartoons/pm/end",
    "type": "video"
}]
